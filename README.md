# Система контроля состояния структурных блоков объекта по временным рядам
Курсовая работа по направлению "Информационные системы и технологии" (09.03.02).
## Описание проекта
Программный комплекс предназначен для приема, обработки и анализа непрерывно-дискретных временных рядом с целью контроля текущего состояния структурных блоков и своевременного обнаружения отклонений.
## Основной функционал
* **Математическое моделирование:** Расчет показателей состояния блоков на основе поступающих временных рядов.
* **Архитектура и БД:** Хранение истории измерений и результатов анализа в базе данных (sqlite).
* **Визуализация:** Отображение графиков и динамики состояния блоков в реальном времени. 
* **Тестирование:** Проведена функциональная проверка работы системы методом "черного ящика".
## Инструкция по запуску
1. Клонировать репозиторий: git clone https://github.com/errixenon/IS-analysis-manmade-object.git
2. В открытой программе первым этапом нужно открыть базу данных, соответствующей кнопкой. Для примера функционирования программы можно выбрать файл "база данных.db", а для проверки программы методом "черного ящика", можно выбрать один из тестов в папке "тестирование".
